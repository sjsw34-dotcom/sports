# UX_PRINCIPLES.md — 모바일 학습 UX 원칙

## 1. 기본 전제

- **모바일 우선**. 데스크톱은 반응형으로 대응하되 우선순위는 낮음.
- **지하철/침대/카페**에서 한 손으로 쓴다고 가정.
- **3초 안에 다음 문제로**: 학습 흐름을 끊지 않는 게 최우선.

## 2. 레이아웃

### 2.1 화면 3분할
모바일 화면을 세로로 3등분해 사고한다.

```
┌─────────────────┐
│  상단 1/3       │  ← 문제 본문 (스크롤 가능)
├─────────────────┤
│  중단 1/3       │  ← 선택지
├─────────────────┤
│  하단 1/3       │  ← 주요 액션 버튼, 네비
└─────────────────┘
```

주요 액션은 **반드시 하단 1/3에** 배치. 엄지 영역(thumb zone) 고려.

### 2.2 하단 고정 네비

```
홈 | 과목 | 기출 | 오답 | 통계
```

- 아이콘 + 한글 라벨 (아이콘만 있으면 인지 부담 증가)
- 현재 탭은 색상 + 두꺼운 라벨로 강조

### 2.3 상단 바
- 과목명 + 현재 진행 상황 (`15 / 20`)
- 좌측: 뒤로가기 (chevron)
- 우측: 북마크 토글 (별 아이콘)

## 3. 타이포그래피

- **본문 최소 16px** (iOS 자동 줌 방지 필수)
- **문제 본문**: 18px, line-height 1.7
- **선택지**: 16px, line-height 1.6
- **해설**: 15px, line-height 1.7, 배경 약간 다른 색
- 한글 폰트: Pretendard (시스템 폰트 fallback)

## 4. 인터랙션

### 4.1 선택지 탭
- 탭 → 즉시 정답/오답 피드백 (색상 + 햅틱)
- 정답: 초록 테두리 + 체크 아이콘
- 오답: 빨강 테두리 + X 아이콘 + 정답 초록 표시
- **답을 누른 후에만 해설 표시** (엿보기 방지)

### 4.2 스와이프
- **좌 → 우**: 이전 문제
- **우 → 좌**: 다음 문제 (단, 답을 안 골랐으면 확인 토스트)
- **아래 → 위**: 해설 패널 펼침
- **위 → 아래**: 해설 패널 접음

### 4.3 개념 링크 탭
- 해설 안 `{{concept:...}}` 탭 → **바텀시트** (페이지 이동 아님)
- 바텀시트 높이 최대 70vh
- 상단 드래그 핸들로 닫기 가능

### 4.4 버튼 크기
- **최소 44x44px** 터치 타겟 (Apple HIG)
- 주요 CTA는 56px 높이 권장
- 버튼 간 최소 8px 간격

## 5. 색상 및 테마

### 5.1 라이트 모드
- 배경: `#FFFFFF`
- 본문: `#18181B`
- 강조: `#6366F1` (인디고)

### 5.2 다크 모드 (기본)
- 배경: `#0A0A0A`
- 본문: `#FAFAFA`
- 강조: `#A78BFA` (라이트 퍼플)

> 체육지도자 공부는 밤에 누워서 하는 경우가 많음. **다크 모드를 기본값으로**.

### 5.3 정답/오답
- 정답: `#10B981` (에메랄드)
- 오답: `#EF4444` (레드)
- 북마크: `#F59E0B` (앰버)

### 5.4 과목별 테마 컬러
각 과목에 고유 색상 부여 (`subjects.json`의 `color` 필드).
과목 페이지 상단, 과목 필터 칩 등에 반영.

## 6. 상태 및 피드백

- **로딩**: 스켈레톤 UI (스피너 금지, 화면 깜빡임 방지)
- **에러**: 하단 토스트, 3초 후 자동 사라짐
- **성공**: 하단 토스트 + 햅틱 피드백 (iOS/Android)
- **빈 상태**: 친절한 일러스트 + 다음 액션 유도 버튼

## 7. 접근성

- 모든 아이콘 버튼에 `aria-label`
- 색상만으로 정보 전달 금지 (정답 표시는 색+아이콘+텍스트)
- 포커스 링 유지
- 다크 모드 대비율 WCAG AA 이상

## 8. 성능

- 첫 화면 렌더 1초 이내
- Lighthouse Mobile Performance 90+ 목표
- 이미지는 next/image + lazy load
- JSON 데이터는 과목별로 code-split

## 9. PWA 체크리스트

- [ ] manifest.json (이름, 아이콘, theme_color)
- [ ] 서비스 워커로 데이터 오프라인 캐시

- [ ] 아이콘 192x192, 512x512
