# 기출문제 PDF 원본

연도별로 정리된 체육지도자 자격증 필기시험 기출문제 및 정답가안 PDF 모음.

## 폴더 구조

```
public/exams/
├── 2019/   # 1급·2급 생활/전문/장애인/유소년/노인 + 정답가안
├── 2020/   # 위 + 건강운동관리사
├── 2021/
├── 2022/
├── 2023/
├── 2024/
├── 2025/
└── 2026/
```

## 용도

- **앱에서는 읽지 않는다.** 앱은 `/data/questions/**/*.json`만 읽는다.
- PDF는 다운로드/원본 확인용으로만 제공.
- `scripts/pdf_to_json.py`로 JSON 변환하는 소스로 사용.

## Git 추적

PDF 파일은 용량이 커서 `.gitignore`로 제외되어 있다. 로컬에서만 유지.
추후 필요 시 Git LFS 또는 외부 스토리지로 이관 고려.
